# Control Gallery delivery stages

The stages are ordered outcomes, not a record of packets, agents, pull requests, or implementation attempts.

1. [Gallery foundation and test harness](milestones/gallery-foundation.md)
2. [Foundations and field controls](milestones/field-controls.md)
3. [Actions, selection, search, and feedback](milestones/interactions-and-feedback.md)
4. [Overlay and navigation controls](milestones/overlays-and-navigation.md)
