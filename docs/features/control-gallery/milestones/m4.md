## Routing forecast

M4 targets **60–70% accepted local code-bearing lines**. Overlay foundation, Dialog, Menu, public exports, gallery integration, and the highest-risk focus specification remain coordinator-owned; local packets are limited to one control or one test behavior group.

## Acceptance criteria

- Dialog and Drawer trap/contain focus as specified, close on Escape, and restore focus to their trigger.
- Popover and Menu use their documented outside-dismissal behavior and do not leave orphaned open state.
- Tabs support pointer selection and Arrow-key movement, with one selected tab and one visible panel.
- All overlay and navigation examples work at narrow and wide widths.

## Invariants

- No hidden overlay retains focus.
- Closing an overlay restores focus to its last valid trigger.
- Exactly one tab panel is visible for each tab set.

## CG-M4-01 — Overlay foundation contract

**Entry:** A later overlay component renders inside `OverlayRoot`, captures its invoking element before opening, and calls `useOverlayLayer` while open. The foundation records layers in last-in-first-out order; a layer can tell whether it is the active top layer.

**Exit and recovery:** Removing the active top layer attempts one focus restoration to its captured trigger. Restoration succeeds only when that trigger is still connected, enabled, and not inside an inert ancestor. If the trigger is gone or unavailable, the foundation does not invent a fallback target, focus the document body, or throw; the later control owns any workflow-specific fallback. Removing a non-top layer does not steal focus from the active top layer.

**Alternate paths and refusal:** Opening without a captured trigger records no trigger and therefore has no restoration target. A missing `OverlayRoot` is a programming error and throws before registration. This packet does not render a visible layer, establish `dialog`/`menu` semantics, add a portal/backdrop, process Escape or pointer dismissal, or impose a focus trap; later component packets opt into the exported helpers according to their approved behavior.

**Shared helpers:** The foundation supplies focusable-descendant discovery, first-focus placement, and a Tab/Shift+Tab cycle helper. Helpers ignore disabled, hidden, and inert descendants; first-focus returns false when there is no focusable target. Modal containment and initial-focus choice are exercised by Dialog/Drawer, not assumed by every overlay.

**Validation:** Foundation jsdom tests prove active-layer ordering, captured-trigger restoration, stale/disabled/inert trigger refusal, non-top removal, focusable filtering, no-target initial-focus result, and Tab-cycle boundaries. TypeScript, static check, production build, source scope/diff checks, and independent review are required. Browser behavior is `UNTESTED` in this packet because no gallery-facing overlay exists until later M4 packets.
