# M1 — Gallery foundation and test harness

## Scope

Create the React/TypeScript workspace and the reusable gallery/test infrastructure. The existing dependency-free prototype is retained only as behavior reference until its React replacement is accepted.

## Acceptance criteria

- A fresh checkout installs and runs using documented commands.
- The gallery is a React/TypeScript app; the prototype is no longer its runtime entry point.
- Gallery navigation reaches each planned family and has visible keyboard focus.
- Reduced-motion preference changes the gallery behavior without hiding content.
- A browser spec runs against the actual gallery and proves direct load and navigation.
- Public foundation exports enforce the approved Control Base and skin/locale boundaries before any concrete control is added.

## Non-goals

- Shipping Core v1 controls beyond the minimum shell used by the gallery.
- Vennusign integration or skin reuse.

## Verification

1. Install command from a clean workspace.
2. Production build command.
3. Browser spec command.
4. Manual narrow and wide width check.
5. Independent review of the exact commit.
