## Acceptance criteria

- Every row in `path-coverage.md` is evidenced or explicitly marked `UNTESTED` with a reason.
- Each Core v1 control family has a real gallery example and documented keyboard behavior.
- The gallery is checked at smallest and largest supported widths, including long content and empty states.
- Independent review returns `APPROVE`, or material findings are resolved before owner acceptance.
- Owner acceptance can be completed in 5–10 minutes without invoking Vennusign conversion work.
- Token, label-catalog, Control Base, and declared style-extension validation run against the real package before acceptance.

## Non-goals

- Starting a Vennusign adoption plan.
- Extending Core v1 while acceptance is still open.
